Page 4 — API, Integration, and Data Validation

Available routes (GET): /api/fixtures accepts optional competition and team; competition must match 2–8 uppercase alphanumeric characters after normalization, team maximum 100 characters. It queries Football-data.org matches for yesterday through seven days ahead. /api/standings accepts optional competition, default PL; allowed codes: PL, CL, PD, BL1, SA, FL1. /api/sports-news requires club (1–100 chars); optional league; sources Google News RSS. /api/supabase-check checks Supabase Auth health. No API documentation file was found.

Execution: In authorized non-production environment, request each known route using Postman/curl. Check HTTP status, JSON content type, response shape, UI rendering, and provider failures. Do not submit writes to database through ad hoc requests; no write API contract is documented. Never include keys/tokens in evidence.
